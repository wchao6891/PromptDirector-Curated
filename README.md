# PromptDirector Curated

PromptDirector 的公开精选案例目录。

这个仓库只保存开发者审核后可公开分发的目录、封面和投稿入口。插件源码、私人案例、评测资料、同步数据和 API 密钥不属于本仓库。

## 发布流程

1. 投稿者从 PromptDirector 的项目菜单生成精选投稿包。
2. 投稿者在 Issue Form 中附上 ZIP、署名、授权与说明。
3. 维护者人工检查版权、隐私、重复内容、ZIP 完整性和案例质量。
4. 通过审核的 ZIP 作为 GitHub Release 附件发布。
5. 维护者将封面放入 `site/covers/`，并把带 SHA-256 校验值的记录加入 `site/catalog.json`。

目录不会自动收录投稿，不提供点赞、评论、关注或排行榜。
