01 / FIRST CASE

Save your first case

Install once, and anything you like can go straight into your library.

01

Install the extension

The quickest way is the Chrome Web Store: click “Add to Chrome”. If you prefer the ZIP from GitHub, download the latest release and unzip it; type chrome://extensions in Chrome's address bar, turn on “Developer mode”, click “Load unpacked”, and select the unzipped extension folder.

Chrome Web StoreOpen the install page ↗ 1.24.1 release packageDownload the ZIP ↗

Once it is installed, click the puzzle-piece icon to the right of the address bar and pin PromptDirector to the toolbar. The steps below start with clicking the extension icon.

02

Open a work and click “Web capture”

Open the page with the work you want to save, click the PromptDirector icon in the Chrome toolbar, then click the green “Web capture” button in the panel.

The first time an authorization prompt appears, click “Authorize and continue”; the extension will not save the page on its own.

03

Check the preview and save the case

The panel shows the text and media it found. If it is the work you want, click “Save case” at the bottom. If the media is wrong, expand “Review media” first.

04

Open the case library

Go back to the panel and click the library icon in the top-right corner. When the case library opens, the case you just saved is in the list; you can also find it with the search box at the top.

✓

Open a case to see its details

Click any case card to see the original visual, the original prompt, the source and the project. From there you can also click “Create from this”.

02 / BUILD YOUR LIBRARY

Collect and organize material

Find the entry point first, then see what is behind it.

Curated cases

Bring curated packs into your own library

In the case library, click “Curated cases” on the left, open a pack you like, then click “Save whole pack”.

ZIP import and sharing

Bring case packs in and send them out

Import: gear icon in the top-right of the case library → “Interface and library” → “Import share package” → “Choose ZIP”. Export: click “Manage”, select cases → “More” → “Share” → “Download shared pack”.

Batch visual analysis

Analyze several visuals at once

First connect an image or video analysis service in the AI settings. Back in the case library, click “Manage” in the top-right, select cases → “More” → the matching batch analysis. When videos are selected, image analysis is greyed out; check the number of requests and the cost before you run it.

03 / CREATE WITH REFERENCES

Create with cases

Connect your own AI service, then let cases and Creative Skills feed your next creation.

Before you start

Connect an AI service

Gear icon in the top-right of the case library → “AI settings” → “Service connections” → “Connect AI service”. After saving the service, choose models for image analysis, creation planning and other tasks on the “Task models” page. Calls to the service may cost money.

Composer

Just say what you want to make

Click “Create” in the top-right of the case library. Write your goal at the bottom of the composer — for example “write me a cinematic character poster prompt” — then send it.

Search from the composer

Let the composer find things in your library

Make sure the magnifier next to the input box is on, then just say “find me a few rainy-night street references”. Models that support library search will show the cases they found and read; if the current model does not support it, pick them by hand with “Reference”.

Reference cases

Pick visuals, then generate a prompt

At the bottom of the composer, click “Reference”, search and tick the works you want to learn from on the “Cases” tab, then click “Apply references” in the bottom-right. Go back to the input box and write your goal.

Creative Skill

Save a method as a Skill

In the case library, click “Creative Skill” on the left, then “New Skill” in the top-right. Follow the page prompts: choose the source cases, describe the method you want to distill, review the draft and save.

Skill + cases

Use a method and references together

In the composer, click “Reference”, choose your material on the “Cases” and “Skill” tabs, apply it, then write your goal and send. If you need the model to look at the images themselves, also turn on “Send original images too”.

04 / MORE WHEN NEEDED

Once you are comfortable, explore these

These are the other features used in your screenshots; you can skip them the first time you save a case.

Projects

Organize by project

Click the plus next to “Projects” on the left to create one; the “…” to the right of a project lets you manage its cases.

Type

Find by content type

Expand “Content type” on the left and click image prompts, video or documents.

Tags

Find by tag

Expand “Tag filter” and click a theme, style or color tag to narrow things down.

View

Switch how you browse

The picture icon and the list icon at the top switch between masonry and list.

Save

Download curated Skills

On the “Curated Skills” page, click “Save locally”; you can then use it in the composer.

Direction

Choose image or video

Open “Creation direction” at the bottom of the composer and choose image creation or video creation.

Add

Import local files

“Add” in the top-right of the case library imports files, saves video links or writes a quick note.

Add in

When the prompt is in the comments

Capture the work first, then add the prompt from the comments to the current case, and check it before saving.

Model

Switch the creation model

Next to the composer's send button you can switch between connected models.

Task

Adjust this round of creation

Click the gear next to the input box to choose the task, the output language and more.

Method

Customize the creation method

Settings → “Analysis & creation rules” → “Creation method”, and edit as needed.

Tag

Backfill text tags for older cases

In Settings → “Tasks & maintenance”, check how many are pending, then decide whether to start.
