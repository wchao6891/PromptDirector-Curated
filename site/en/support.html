PromptDirector Support

Installation, usage, data safety, and feedback

Get help

If the extension cannot install, capture, organize, back up, or create, first update Chrome and record the extension version, Chrome version, steps taken, and the result you observed.

  • For product issues and feature requests, use PromptDirector issue reporting. A GitHub sign-in is required to submit.
  • You can also open the Chrome Web Store listing and use its Support entry to contact the developer.
  • For privacy and data-handling details, read the privacy policy.

Before submitting feedback

Do not publicly submit API keys, cookies, tokens, private library content, or unlicensed media. Share only redacted screenshots, reproduction steps, and error text when needed.
