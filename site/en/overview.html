What it does

Most prompt tools start from an empty box. The references you actually want are already out there — in a gallery post, a tweet, a video breakdown. PromptDirector works where you find them.

01

Capture the work and its clues

One click keeps the image or video together with the publicly available prompt, the source page, the author and the capture time — not just a screenshot.

02

A library that stays yours

Cases, media, tags, Creative Skills and settings live in your browser's local storage. No account, no analytics, no developer-operated data server.

03

Find it again

Browse visually, filter by content type and tags, sort by project, and keep multi-image works, article structure and table layouts intact.

04

Put it to work

Extract reusable Creative Skills, compose new images or video through your own AI service, and let a local MCP agent search, read and save into the same library.

How it works

  1. Open the work, post or article Open the page in Chrome. PromptDirector reads the tab only after you start a capture.
  2. Capture it Use the side panel, the right-click entry or the keyboard shortcut, then correct the detected subject, text and media if needed.
  3. Preview and save Confirming the subject does not confirm its media: only the media you explicitly approve is written to a case.

Before you install

  • Chrome 134 or newer.
  • Capture and organizing need no AI service and no account.
  • Capture works on pages you can already access; it does not bypass logins, paywalls, access controls or CAPTCHAs.
  • Original prompts must be publicly visible on the page. Login state, lazy loading and site changes can affect results.
  • Preview before saving — public URLs may be shown for review, but only media you confirm is written to a case.
  • Optional AI features use your own API key and run only when you start them.
  • Website access is optional and requested per feature; it is not granted at install time and does not monitor browsing.
  • Your cases stay on your machine. See the privacy policy for the data each action handles.

Free to use. If you want your reference library to be structured data instead of a folder of screenshots, install it and save your first case — it takes about five minutes.
