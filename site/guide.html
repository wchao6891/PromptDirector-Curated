01 / FIRST CASE

先保存一条案例

安装一次，以后看到喜欢的作品就能直接收进库。

01

安装插件

优先打开 Chrome 商店，点“添加至 Chrome”。如需从 GitHub 安装，从发布页下载最新 ZIP 并解压；在 Chrome 地址栏输入 chrome://extensions，开启“开发者模式”，点“加载已解压的扩展程序”，选择解压出的插件文件夹。

Chrome 商店打开安装页面 ↗ 最新发布包下载 ZIP ↗

装好后，点地址栏右侧的拼图图标，把 PromptDirector 固定在工具栏。下面从点击插件图标开始。

02

打开作品，点“网页采集”

打开想保存的作品页面，点 Chrome 工具栏中的 PromptDirector 图标，再点采集栏里的绿色“网页采集”。

首次出现授权提示时，点“授权并继续”；插件不会因此自动保存网页。

03

检查预览，保存案例

采集栏会显示找到的文字和媒体。确认是你想要的作品，再点底部“保存案例”。媒体不对时先展开“检查媒体”。

04

从哪儿进案例库？

回到采集栏，点右上角的书架形图标。案例库打开后，刚保存的案例会出现在列表里；也能用顶部搜索框找。

✓

点开案例看资料

点任意案例卡片，就能查看原画面、原始提示词、来源和项目。看完也可以点“以此创作”。

02 / BUILD YOUR LIBRARY

获取与整理资料

先找入口，再看点进去的页面。

精选案例

把精选包收进自己的库

案例库左侧点“精选案例”，打开喜欢的包，再点“保存整包”。

ZIP 导入与分享

把案例包带进来、发出去

导入：案例库右上角齿轮 →“界面与资料库”→“导入分享包”→“选择 ZIP”。导出：点“管理”，选中案例 →“更多”→“分享”→“下载分享包”。

批量视觉分析

一次分析多条画面

先在 AI 设置里连好图片或视频分析服务。回到案例库，点右上角“管理”，选中案例 →“更多”→ 对应的批量分析。选视频时图片分析会置灰；运行前查看请求数量和费用。

03 / CREATE WITH REFERENCES

用案例创作

连接自己的 AI 服务，再让案例和 Skill 为下一次创作提供参考。

开始前

接入 AI 服务

案例库右上角齿轮 →“AI 配置”→“服务连接”→“连接 AI 服务”。保存服务后，在“任务模型”页给图片分析、创作规划等任务选择模型。调用服务可能产生费用。

创作台

直接说你要做什么

案例库右上角点“开始创作”。在创作台底部写目标，例如“帮我写一条电影感角色海报提示词”，然后发送。

创作台查资料

让创作台找库里的内容

确认输入框旁的放大镜亮着，然后直接说“帮我找几条雨夜街道参考”。支持查库的模型会显示找到、读取的案例；若当前模型不支持，可用“参考”手选。

参考案例

选画面，再生成提示词

创作台底部点“参考”，在“案例”页搜索和勾选想借鉴的作品，再点右下角“应用参考”。回到输入框写创作目标。

创作 Skill

把方法保存成 Skill

案例库左侧点“创作 Skill”，再点右上角“新建 Skill”。按页面提示选来源案例、写明想提炼的方法，检查草稿后保存。

Skill + 案例

方法和参考一起用

创作台点“参考”，在“案例”和“Skill”两个页签分别选好内容，应用后写目标并发送。需要模型直接看图片时，再开启“同时发送原图”。

04 / MORE WHEN NEEDED

用熟后，再看这些入口

下面是你截图里常用的其他功能；第一次保存案例时可以先跳过。

项目

按项目整理

左侧“项目”旁点加号新建；项目右侧“…”可管理案例。

分类

按内容类型找

左侧展开“内容类型”，直接点图片提示词、视频或文档。

标签

按标签找

展开“标签筛选”，点主题、风格或色彩标签缩小范围。

视图

切换看图方式

顶部的画面图标和列表图标，可切换瀑布流与列表。

保存

下载精选 Skill

在“精选 Skill”页点“保存到本地”，之后可在创作台使用。

方向

选图片或视频方向

创作台底部打开“创作方向”，选图片创作或视频创作。

添加

导入本机资料

案例库右上角“添加”可导入文件、保存视频链接或写快速笔记。

补入

提示词在评论里

先采集作品，再将评论中的提示词补入当前案例，保存前核对。

模型

切换创作模型

创作台发送按钮旁可切换已连接的模型。

任务

调整本轮创作

点输入框旁的齿轮，可选任务、输出语言等。

方法

自定义创作方法

设置 →“分析与创作规则”→“创作方法”，按需修改。

打标

补全旧案例的文字标签

设置 →“任务与维护”中查看待补数量，再决定是否开始。
