# 巨物与微缩的尺度证据

让观众直观判断“它有多大、多小，以及这改变了什么”。用于巨兽、宏大建筑、微缩人物、尺度反转与奇观揭示。

## 选择尺度依据
选择观众熟悉的参照：门、人、车辆、杯子、楼层。至少在关键画面中让主体和参照同框或通过连续镜头建立关系。数字只用于确有设定的绝对尺寸；其余用可见比例，不能只写“无限巨大”。

C028 的怪物超过近旁高楼，触手与公交车、街道发生作用。C238 的小人物必须双手抱住接近头部大小的食物，最后仍维持该比例。C005 的危险来自大板块闭合与小飞船通过的关系，而不是大场景空镜。C147 通过不断拉远把棋盘意象扩展到地貌，属于超现实尺度揭示，不是尺寸恒定的纪录片。

## 给尺度一条因果链
大体量移动会影响接触点与周围：承重处先受力、结构随后失稳、尘土水体再响应。选择可看见的接触点，让崩塌从作用位置发展，别让整座城同时随意爆炸。

微缩主体面对日常物件时，改变动作成本：杯缘像墙，桌面纹理像地形，液滴变障碍。人物本身比例可以保持，不能仅把人物缩小后让他轻易完成普通成人的每个动作。

不要把“巨大”一律等同慢动作。需要迅猛巨兽时，保持接触与惯性证据，摄影机仍能读清动作；需要沉重守卫时，动作启动、停止和环境响应体现重量。遵循任务的物理风格，不把超现实作品写成科学演示。

## 规划观看路径
先让观众认识参照物，再改变视距或显露完整主体。可从足边人群、手边窗户、食物边缘出发，逐渐露出整体。揭示后保留一个已见锚点，防止被误认为换景。

摄影机低不自动等于巨物，浅景深也不自动等于微缩。分别指定摄影机相对于主体的位置、前景参照、遮挡和运动。缩小主体的外观与重力规则要彼此一致；用户要玩具广告时可以选择微缩摄影感，不默认所有场景都移轴虚化。

## 迁移示例（本包新写）
```text
镜头从一扇正常尺寸的车站窗户开始，窗内站着候车的人。外侧一根金属手指缓缓接近，指腹比整扇窗宽。
手指触到窗外石柱，石面在接触点出现裂缝，细灰先落下；随后柱身弯折，玻璃才随结构变形碎裂。窗内人后退，保留人与窗的比例。
摄影机沿车站外墙后退并上升，露出巨型机械人蹲在车站旁。刚才的窗户仍在其指尖旁可见，作为从局部到整体的尺度锚点。
机械人撤手后，裂柱和碎玻璃继续留在原处；地面尘土渐落，不用整屏爆炸遮住动作结果。
```

## 检查
远近镜头中主体与锚点的比例是否漂移；接触是否先于损坏；局部破坏是否在后续保留；摄影机移动有没有无故把主体放大或变小；揭示后是否还能找到原锚点。

输出尺度关系、关键接触/揭示事件和提示词。视频生成尚未执行时不承诺重量、透视或物理正确；需要据成片定位具体失败帧再修正。
