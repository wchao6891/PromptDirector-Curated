# 手机实拍感与拍摄者逻辑

让生成视频体现一个具体拍摄者和拍摄条件。适用Vlog、虚构现场片、手机人像和纪实风创作；不把合成内容包装为真实事件证据。

## 决定镜头是谁的
先确定自拍、朋友跟拍、路人旁观、车内拍摄或固定支架。写清手持者的位置和行动范围。副驾镜头不能无故绕到车外；自拍不能无缘无故看到拍摄者背面。

摄影机注意力跟随事件。先发生声响或动作，再稍晚转向寻找，找到后稳定一下。C188 的副驾视角以道路震动、数字变焦和迟到的反应建立现场感；不代表每个手机镜头都该剧烈晃动。

## 选择真正相关的瑕疵
- 行走：步伐造成轻微起伏，停下来后逐渐平稳。
- 对焦：主体距离改变、前景遮挡时才有找焦理由；证据动作发生时要能看清。
- 曝光：明暗空间切换时自然调整，不持续闪烁。
- 数字变焦：摄影机位置不变，画面裁切放大，细节与稳定性可下降。
- 主体靠近：透视和遮挡真实改变。C026 明确区分了远处变焦与结尾人物靠近。
- 皮肤：依据人物本来的肤色、年龄、妆容和光线保留微纹理；不把毛孔、斑点、油光统一加给所有人。

手机、DV、16mm胶片是不同的视觉机制。C098 的肩扛纪实和胶片颗粒只适用于相应任务，不能和“原生手机无调色”机械叠加。C051 的直射光微距、C119 的柔窗光固定人像也不应混成一个万能人像配方。

## 组织事件
先安排拍摄者会选择记录的事情：等人、买东西、走进房间、转身发现异常。环境中的闲杂变化可以存在，但别抢走关键人物。给行为结果一点可读时间，不把“不完美”解释成主体永远离焦、五官漂移或镜头完全失控。

明确剪辑方式。Vlog可以硬切多个日常片段；隐藏剪辑只在本来允许的遮挡或甩镜中接续，不能声称真实一镜到底。沿用C026时学习转场方向与遮挡逻辑，不继承固定两次甩镜、鞋子或角色设定。

## 迁移示例（本包新写）
```text
朋友在厨房门口用手机拍一位成年人做早餐。摄影机维持门口附近的肩部高度，偶尔随拍摄者换脚产生小幅漂移。
烤面包机发出弹起声后，拍摄者才转向它，略晚跟上。主角伸手取吐司，镜头移回手和盘子；短暂对焦后让取放动作清晰可见。
主角发现镜头，笑了一下，继续把早餐放到餐桌上。摄影机随她走两步，步伐带来轻微起伏，停下后稳定。
自然窗光、真实肤色和厨房环境声。没有连续抽搐式晃动，没有无人机般穿过橱柜，没有为展示皮肤凭空增加雀斑。
```

## 交付与检查
给拍摄条件、事件顺序和完整提示词；只有用户要分镜时才附逐镜表。看成片时核对：机位是否可达、转向是否有动机、失焦是否遮住关键动作、纹理是否属于人物而不是浮在画面上的噪点。处理失败先减掉相互冲突的摄影词，再修必要的动作接续。
