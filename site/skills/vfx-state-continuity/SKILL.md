# 特效的触发、变形与状态连续

解决特效提前亮起、道具变形、消失重生和没有来源的粒子。适用于能量觉醒、材质变化、机械变形、物件重组与建筑复原。

## 先写物体和状态
从用户目标中找出变化对象及不变对象。为重要对象记录“初始形态/位置 → 触发事件 → 转换过程 → 最终形态/位置”。只记录影响成片理解的对象，不给每粒尘埃建表。

- 实体与光分离：C177 的剑始终是固定长度的金属实体，发光层沿剑身展开；地面灼痕属于地面，不能拖成加长光剑。
- 来源与目的地分离：C179 的粒子来自封印，沿既有断柱生长为石材。剑熄灭后，粒子才接过主光源。
- 部件对应：C082 让车灯成为眼睛、轮胎成为关节。机械变形要有折叠、滑轨、展开与锁定；软体融化不等于机械变形。
- 连续材料：C141 用同一根绳形成字形，不能凭空出现第二份文字。终帧图控制目标形状，不等于整个过程静止。

## 用触发条件组织时序
先写动作因果，再分配时间。用户没有精确卡点需求时，用“握稳剑后”“封印破裂时”等事件触发，比到处重复精确秒数更清楚。需要对齐音乐或广告切点时，用一张时序表集中管理时间、光效、亮度、声音与对象状态。

同一状态只定义一处。不要在全局写“剑先不亮”，在动作段又写“发光剑从第一帧划过”。检查参考图已经带特效时是否与初始状态冲突，明确初态保留实体但暂不点亮。

特效还必须改变周围：光照影响邻近表面，冲击推动水雾，碎片落地后留下残骸。选择与故事相符的反馈，不给所有效果一律加入爆炸、白闪、震屏。

## 迁移示例（本包新写）
```text
石灯最初破裂且不发光，碎片散落在底座旁。修复者把一枚铜环放入底座凹槽，接触完成后，凹槽才亮起微弱暖光。
附近碎片依次离地，沿各自距离最短的连续路径回到原断口。碎片仍为不透明石材，边缘逐块对合，不突然替换成一盏全新石灯。
最后一块石片闭合后，底座光逐渐熄灭，灯芯接过主光源。暖光映在刚修复的裂纹和修复者手上。
石灯保持原高度、轮廓与位置，铜环留在凹槽内。已经复位的石片不再次飞出，结尾不重复修复过程。
```

## 输出与修正
交付简短状态表、连续提示词和需要参考图的对象说明。参数来自用户、素材或明确创作决定；不沿用参考片的统一30秒、颜色比例或软件渲染名词当作保证。

特效提前出现：修正初态与触发，清除冲突形容词。形体漂移：分开实体尺寸和光效范围。粒子空降：补发射位置与路径。结尾复活：明确最终状态持续。亮度把关键动作淹没：让高潮后回落到可读状态，不简单把所有光压暗。

原案例体现提示词设计思路，不证明目标模型可精确执行每个秒点；没有生成结果时只报告文字与因果核对。
