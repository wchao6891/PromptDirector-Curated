# 时间冻结、环绕与倒放

把“时间停止”拆成谁停、谁动、摄影机怎样穿过空间、何时恢复。适用于子弹时间、冻结场景穿行、局部时间例外和倒放叙事。

## 选择时间机制
- 世界冻结、摄影机移动：静止物体必须产生随摄影机位置变化的遮挡与视差。C001 是穿行，不要求完成一整圈。
- 世界冻结、主角例外：写明哪部分仍能动，其他物件不能跟着主角恢复。C032 的主角可以喝饮料，背景先停后倒放。
- 身体冻结、眼神例外：C257 只允许眼球动作；摄影机绕到背后时眼神不能穿过头骨追踪，重新可见后再衔接。
- 倒放：原事件沿原路径回到较早状态。不是再生成一次相似事故，也不是所有东西一齐飞回中心。

用户只要静止环绕时，不自动添加倒放、爆炸和反转故事。不要同时写“绝对冻结”和“所有人缓慢动作”；慢动作、静止、倒放是不同状态。

## 安排镜头
按事件写状态表：正常运动 → 触发瞬间 → 冻结或局部例外 → 倒放或恢复 → 结束状态。每段分别列世界、主角、摄影机、声音。时长来自用户需求或素材；无硬要求时以动作可读为依据安排，并说明建议。

冻结选在最能读懂因果的一瞬：手仍接近碰倒的物体，液滴悬空，受惊表情刚形成。冻结前至少让观众看到原因；需要“从第一帧已冻结”则用现场关系交代，不补无关开场。

摄影机路径写起点、经过侧面、遮挡物和终点；环绕不是人物转台，也不是原地摇镜。360°仅在要闭环展示且背面有足够信息时使用。缺少背面资料时指出需推断，不能保证真实重建。具体角速度由角度和时长推得，不能照抄 C257 的数字。

恢复时遵守同一事件的时间方向：正向继续落下，倒放则液体回杯、碎片回位、人物回姿。复位后若主角改变事件，写出新的动作和避免事故的可见证据。

## 迁移示例（本包新写）
```text
玻璃杯被手肘碰到，倾斜越过桌沿；咖啡刚离开杯口时世界完全冻结。杯、液滴、人物衣物与表情全部静止。
摄影机从桌角沿弧线移到杯的侧后方，经过前景液滴，桌缘与背景窗户产生不同速度的视差。只有桌旁的人能动，她看清杯的下落方向后收回手。
随后同一杯咖啡沿刚才的运动轨迹倒放：液滴回杯、杯底回桌、手肘回到碰撞之前。摄影机保持连续。
时间恢复后，她把杯子移到桌子内侧。手肘再次经过原位置而没有碰杯，明确显示事件已经改变。
```

## 检查与修正
- 有“定格截图旋转”感：补真实空间穿行、遮挡和近远景视差，减少没有依据的大幅绕背。
- 头或身体跟镜头转：明确身体坐标固定，摄影机在移动；只保留需要的例外。
- 倒放变成吸入旋涡：写物体各自原路径与复位状态。
- 恢复后重演同一事故：给主角一个改变原因的动作。
- 音频若仍正常流动，说明它属于配乐、主角或外部旁观；不要让被冻结对象持续发出新的动作声。

输出机制说明、状态表及一段连贯提示词。具体秒数是编排目标，实际生成仍需回看核验。
